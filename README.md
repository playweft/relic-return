# 归核 / Relic Return

一款可在浏览器中游玩的第三人称遗迹冒险游戏。穿过苔光营地、回声中庭和琥珀庭院，寻找开启圣所的钥匙，击败守卫，将能量核心带回营地。

## 游戏玩法

每局最多五分钟，包含探索、战斗和返回交付：

1. 从营地出发，进入中庭，沿西侧岔路寻找琥珀钥匙。
2. 返回中庭，消耗钥匙开启北侧封印。
3. 避开守卫的挥击，抓住时机反击，取得能量核心。
4. 沿原路返回营地，交付核心完成远征。

游戏提供一个携带槽。钥匙开门后消耗，腾出的槽位用于携带核心。结算显示用时、剩余生命及守卫、陷阱、跌落造成的伤害，并支持导出本局记录。

### 难度

| 阶段 | 挑战 |
| --- | --- |
| Ⅰ · 初探 | 无陷阱，熟悉路线与战斗 |
| Ⅱ · 遗迹 | 加入周期激活的符文陷阱 |
| Ⅲ · 试炼 | 守卫攻击前摇更短，伤害更高 |

三个阶段使用同一张地图和同一套操作。

### 操作

| 按键 | 动作 |
| --- | --- |
| WASD | 相对镜头方向移动 |
| 鼠标拖动 / 方向键 | 调整镜头 |
| 空格 | 跳跃 |
| 鼠标左键单击 / J | 攻击 |
| Shift | 闪避 |
| E | 拾取、开门、交付 |
| Esc | 暂停或继续 |

切换窗口或进入后台时自动暂停。当前支持桌面键鼠操作。

## 本地开发

需要 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev
```

打开 [本地游戏](http://127.0.0.1:9143/)。

```sh
npm test       # 运行自动测试
npm run build  # 生成生产文件
npm run check  # 测试并构建
```

项目使用 Three.js 渲染场景，Vite 负责开发与构建。游戏规则与渲染分离，采用固定 60Hz 步长。场景与角色均使用程序生成的低多边形美术，无需外部素材。

## 部署

项目通过 Cloudflare Workers 静态资源托管发布。连接此仓库时，项目根目录使用仓库根目录，部署命令为：

```sh
npx wrangler deploy
```

`wrangler.jsonc` 中的 `build.command` 会自动执行 `npm run build`。Worker 名为 `relic-return`，静态资源目录固定为 `./dist`。

### 路径配置

默认使用 `BASE_PATH=/`，发布到站点根路径。部署到子路径时，在构建环境设置：

```sh
BASE_PATH=/relic-return/
```

也可以将 `.env.example` 复制为 `.env` 后修改。构建结果如下：

- 游戏文件整体输出到 `dist/relic-return/`。
- 资源地址和 `playweft.json` 中的 `id` 使用相同路径前缀。
- `_headers` 保留在发布根目录 `dist/_headers`，其中的匹配规则自动添加路径前缀。
- `playweft.json` 和 `featured-games.json` 配置跨域访问及禁用缓存。
- 每次构建清空旧输出，切换路径不会遗留之前的文件。

Cloudflare 的静态资源目录始终保持 `./dist`，不要改为嵌套的子目录。

### Playweft 集成

支持通过游戏根 URL 或 `playweft.json` 导入 Playweft，使用标准 MessageChannel bridge 初始化单人游戏。

## 测试与当前范围

自动测试覆盖完整任务流程、封印阻挡、钥匙消耗、攻击触发、跳跃、闪避、陷阱与跌落伤害、结束状态、确定性及子路径构建配置。

当前版本采用平面房间和宽桥。装饰柱与帐篷不参与碰撞，镜头尚未加入遮挡回避，暂不支持手机触控操作。
